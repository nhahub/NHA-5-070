# Class Twin - Phase 1

An AI twin that listens to recorded questions and answers in Ahmed's style.

## Project Goal

Build a tool-using agent that can:

- Transcribe Arabic and English speech
- Decide whether a question is addressed to Ahmed
- Retrieve relevant personal notes and style examples
- Generate a structured response
- Speak the response using text-to-speech

## Phase 1

Phase 1 is tested on recorded audio.

Phase 2 will extend the system to live meetings.
